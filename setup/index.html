Setup guide · version 0.6.0

Set up Fullbars.

Steps 1 to 3 get you live on Twitch from your phone. Steps 4 to 6 are optional: they keep you live in dead zones, add more connections, and send your stream to Kick or YouTube too. Each step says what it costs, how long it takes, and why it's worth it.

  1. 1Install the app2 min · free
  2. 2Sign in with Twitch1 min · free
  3. 3Do a Test stream5 min · your data
  4. 4Set up your BRB server Optional30–60 min · $4–10/month
  5. 5Add helper phones and a hotspot Optional10 min
  6. 6Also stream to Kick or YouTube Optional5 min · free
1

Step 1: Install the app

Time
About 2 minutes
Cost
Free
You need
An Android 12+ phone

WhyFullbars isn't on Google Play yet, so you install the test build from GitHub yourself.

  1. On your phone, open the latest release on GitHub and download the .apk file under Assets.
  2. Open the downloaded file. Android asks whether your browser may install apps: allow it, then tap Install.
  3. Android may warn that the app is unknown. That's normal for apps from outside Google Play.

This is a debug-signed test build. When a release-signed build comes out, you'll need to uninstall this one first.

2

Step 2: Sign in with Twitch

Time
About 1 minute
Cost
Free
You need
Your Twitch login

WhySign in once and Fullbars gets your stream key from Twitch. You never copy or paste it, and the BRB server gets it from the app later.

  1. Open Fullbars and tap Continue with Twitch.
  2. Fullbars shows a short code and opens Twitch. Check the code matches, and approve it.
  3. Back in Fullbars, the Twitch row shows your channel name, and the pre-flight checklist fills in.

Rather not sign in? Tap Use a stream key instead and paste the key from your Twitch dashboard.

3

Step 3: Do a Test stream

Time
About 5 minutes
Cost
Your mobile data
You need
Steps 1 and 2

WhyA test goes all the way to Twitch, but nobody can watch a test on Twitch, not even you. It's where you find out your mic is too loud, not on stream.

  1. Check your mic. Open Settings › Microphone and talk the way you will on stream. Your voice should reach the marked range, and only touch amber when you shout. If you sound too loud or harsh, turn off Phone's auto level and set the level with the fader.
  2. Start the test. On Home, TEST only you is picked by default. Tap Start test.
  3. Walk around. Try the keys along the bottom: BRB puts your BRB card up, SCENES has the rest. The pill at the top says what viewers would see.
  4. End it. Hold END for 2 seconds. The recap shows how long it ran and how many times the connection dropped. Tap Check it arrived in Twitch Inspector to see it on Twitch's side.

After a clean test, Fullbars offers Go live now. That's it: without a server, Fullbars streams straight to Twitch over your phone's connection.

4

Step 4: Set up your BRB server

Optional
Time
30–60 minutes, once
Cost
About $4–10 a month, or Oracle Cloud's free tier
You need
A Mac, a Linux PC, or Windows with WSL

WhyThe BRB server lets your phone use mobile data, Wi‑Fi and helper phones at once, and keeps Twitch live with a Signal lost card when all of them drop. When you're back, your picture returns within seconds. You set it up once and then forget about it.

A server here means a small computer you rent by the month, somewhere with good internet. You'll type a few commands on your own computer; you can copy every one of them from this page. Wherever you see YOUR_SERVER_ADDRESS, use your server's IP address, such as 203.0.113.7.

4aRent a small server

  1. Pick any VPS provider (Hetzner, DigitalOcean, Vultr, OVH and Linode all work) and create the smallest server with Ubuntu 24.04. 1 GB of memory is plenty: the BRB server is capped at 256 MB, uses far less, and needs almost no CPU, because it never re-encodes your video. Pick a location near where you stream.
  2. When it asks how to log in, add an SSH key if you have one, or set a root password and keep it somewhere safe.
  3. Note the server's public IPv4 address. That's your YOUR_SERVER_ADDRESS.

Oracle Cloud's free tier works too, but it's fiddlier: it has two firewalls to open (see 4b).

4bOpen two ports

If your provider has a firewall for the server, allow these. If it doesn't have one, skip this.

PortWhat for
UDP 5000Your phone's stream (required)
TCP 5000The app's secure control connection (required)
UDP 5001Only for My OBS at home
TCP 8181Only for NOALBS stats

On Oracle Cloud, allow UDP and TCP 5000 on the server itself and in the subnet's security list. If either is missing, the app can't reach the server.

4cInstall Docker on the server

Open Terminal (on Windows, the Ubuntu app from WSL) and log in to your server. The first time, type yes when it asks whether to trust the server.

On your computer
ssh root@YOUR_SERVER_ADDRESS

Then install Docker with its official script, and log out:

On the server, after you log in
curl -fsSL https://get.docker.com | sh
exit

4dInstall the BRB server

Back on your own computer, get Fullbars' code and run its install script. It builds and starts one container, fullbars-brb, and only touches /opt/fullbars-brb on the server. The first build takes a few minutes.

On your computer
git clone https://github.com/AnnabelleChimpton/fullbars.git
cd fullbars
server/brb/deploy.sh root@YOUR_SERVER_ADDRESS

No git? On a Mac, running git once offers to install it. You can also download the code as a ZIP from GitHub and run server/brb/deploy.sh from inside it.

When it finishes it lists the ports to open, and the server restarts on its own after a reboot or a crash.

4ePair the app

  1. Make sure you've signed in to Twitch in Fullbars (step 2), or added a stream key. The app sends your Twitch details to the server each time you go live.
  2. On your computer, ask the server for a pairing code:
    On your computer
    ssh -t root@YOUR_SERVER_ADDRESS docker exec -it fullbars-brb brb pair
    A QR code appears in the terminal.
  3. In Fullbars, open Settings › Combine connections, turn on Combine connections, tap Scan pairing code, and scan it.

Treat the code like a password: whoever has it can stream through your server. If it leaks, run docker exec -it fullbars-brb brb pair -reset on the server and pair again.

Done. Do another Test stream: the live screen now shows each connection along the bottom, with its own Mb/s. Fullbars sends your Twitch details to the server each time you go live, so you never put a stream key on the server.

4fIf something's wrong

"Can't reach your BRB server"
Is it running? Log in and run docker ps. Are UDP and TCP 5000 open in every firewall your provider has?
Live, but only one connection shows
Mobile data is off, or Wi‑Fi isn't connected. Combine uses whatever is there.
"This BRB server doesn't know this phone any more"
The server was re-paired or rebuilt. Pair again (4e).
Viewers see nothing
Run docker logs fullbars-brb on the server. "Twitch refused the stream" means Twitch rejected the key: check you're signed in to the right channel in Fullbars.

To update the server later, run git pull in the fullbars folder, then server/brb/deploy.sh again. Your pairing and your cards are kept.

5

Step 5: Add helper phones and a hotspot

Optional
Time
About 10 minutes
Cost
Their data plans
You need
Step 4

WhyEvery extra connection is another way through. Pick ones on a different carrier from your phone's: where one is weak, the other often isn't.

5aA MiFi or other Wi‑Fi hotspot

  1. Connect your streaming phone to the hotspot's Wi‑Fi, like any network. Leave mobile data on.
  2. With Combine connections on, Fullbars uses the hotspot and your mobile data together. Each shows up as its own column on the live screen.

5bA helper phone

Any spare Android 12+ phone with its own SIM and data. It goes in your pocket or bag, and adds its mobile data to your stream.

  1. Install Fullbars on the spare phone (step 1).
  2. On your streaming phone: Settings › Helper phones, turn on Accept helper phones, leave Make a hotspot for helpers on, and allow Nearby devices. Keep Bluetooth on.
  3. On the helper phone: Settings › Helper phones, tap Scan the streaming phone's code, and scan the code your streaming phone shows. Allow Nearby devices, and keep its Bluetooth, Wi‑Fi and mobile data on (the Wi‑Fi doesn't need to be connected to anything). It says it's waiting for you to go live.
  4. Go live. Within about 15 seconds the helper finds your streaming phone's hotspot and asks to connect: tap Connect. On Android 16 it may ask again each stream.

Tested with a Pixel 5 helping a OnePlus 12, including the Pixel carrying the whole stream on its own. Helpers use Moblin's Moblink protocol, so Moblin's helpers should work too, but that hasn't been tested yet.

6

Step 6: Also stream to Kick or YouTube

Optional
Time
About 5 minutes
Cost
Free
You need
Step 4

WhyReach viewers on Kick or YouTube without sending your stream twice. Your phone uploads it once, and your BRB server sends the copies.

  1. In Fullbars, open Settings › Also stream to.
  2. Kick: turn on Stream to Kick. In Kick's creator dashboard, under Settings › Stream, copy the Stream URL and the Stream key into Fullbars.
  3. YouTube: turn on Stream to YouTube. In YouTube Studio, under Go live › Stream, copy the stream key into Fullbars.
  4. Anything else: Other server takes any RTMP address and stream key.
  5. Go live with LIVE · public. Test streams never go to these.

Up to three at once. Each one adds your stream's bitrate to your server's upload, not your phone's. Chat, alerts and mod commands stay on Twitch. If one refuses the stream, Twitch carries on, and the page says why. Set up your server before this feature arrived? Update it first (see the end of 4f).
